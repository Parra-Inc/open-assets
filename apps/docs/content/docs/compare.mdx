Open Assets renders App Store screenshots, app icons and web images from HTML and CSS templates with a free, MIT licensed CLI. The full comparisons, with sourced feature tables and an honest "when to choose them" section for each tool, live on [open-assets.dev/alternatives](https://open-assets.dev/alternatives).

| Tool | Kind | In short |
| --- | --- | --- |
| [fastlane frameit](https://open-assets.dev/alternatives/fastlane-frameit) | Open source CLI | Frames existing screenshots and adds titles from `.strings`. Moving over? See [Migrate from frameit](/migrate/frameit). |
| [Koubou](https://open-assets.dev/alternatives/koubou) | Open source CLI | YAML config, bundled device frames, `.xcstrings` localization and an agent skill. |
| [AppLaunchpad](https://open-assets.dev/alternatives/applaunchpad) | Hosted editor | Browser editor with a large template library. |
| [Screenshots.pro](https://open-assets.dev/alternatives/screenshots-pro) | Hosted editor | Browser editor; localization and an API on paid plans. |
| [AppScreen](https://open-assets.dev/alternatives/appscreen) | Open source web app | Browser editor with a 3D iPhone and AI translation. |
| [Agent skills](https://open-assets.dev/alternatives/agent-skills) | Agent skills | ParthJadhav and framara screenshot skills next to the Open Assets skill. |

## Which one for CLI or CI localization

If you need every language rendered by a command in CI, the candidates are Open Assets, Koubou and fastlane frameit. Open Assets also renders the app icon and web assets from the same templates. See [Localization](/localization) and [CI with GitHub Actions](/ci/github-actions).
