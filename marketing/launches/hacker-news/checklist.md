# HN Pre-Launch Checklist

## Product and page

- [ ] Fresh-machine test: in an empty directory, `npx @open-assets/open-assets init`
      then `npx open-assets dev` opens the viewer and an export succeeds
- [ ] `npx open-assets render` works in the scratch project (cold Puppeteer download path)
- [ ] README top section reads clearly logged out, on mobile (the example galleries are
      the sales pitch, confirm the images load)
- [ ] Repo social preview image set to `public/img/banner/1280.png` and unfurls
      correctly (test by pasting the repo link in Slack/iMessage)
- [ ] npm page looks right: description, keywords, README render on npmjs.com
- [ ] License and pricing story obvious: MIT badge visible above the fold
- [ ] Optional, high value: 10s hot-reload GIF at the top of the README

## Account and standing

- [ ] HN account has some genuine comment karma (spend Sun/Mon commenting on threads
      you actually know; do not submit anything)
- [ ] Nothing about open-assets posted to HN in the last 24 hours
- [ ] Logged in, submit page tested

## Copy

- [ ] Title final, copied from `title.md`, no edits improvised at post time
- [ ] First comment final, `[VERIFY BEFORE POSTING]` placeholder resolved, in clipboard
- [ ] Owned-circle note drafted (personal, no vote language)

## Launch-day logistics

- [ ] Tuesday 8:00 AM to 12:00 PM MT blocked, no meetings
- [ ] Notifications on for HN replies (or a tab pinned on the thread)
- [ ] `follow-up.md` open for capturing questions as they arrive
