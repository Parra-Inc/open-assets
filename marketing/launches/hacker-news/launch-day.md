## Comment handling

| Comment type | Move |
|--------------|------|
| "Why not Fastlane Frameit / screenshots.pro / Figma?" | Gracious, specific: Frameit frames existing captures, this authors the whole composition as code; Figma is the design tool, this is the build pipeline after design is decided. Never trash the alternative. |
| "Puppeteer is heavy" or perf critique | Acknowledge, explain the trade-off (HTML/CSS as the authoring format is the point, headless Chrome is the price), ask what they would use. |
| "AI-generated screenshots will all look the same" | Agree with the risk, point at the four real example apps as the counter-evidence, note the agent is optional. |
| Valid bug or sharp edge | "You're right." Fix-it-live if small, or file it publicly and link the issue in the thread. A landed fix mid-thread is the best possible comment. |
| Feature request | "Good call, noted" with an honest read on whether it fits. |
| Troll / bad faith | One brief factual reply or none. |

failed, not the product. Note what to change, let it ride, and consider a cleaner
