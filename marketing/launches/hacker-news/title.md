# HN Submission Title

## Recommended

```
Show HN: Open Assets - Storybook for App Store screenshots, icons, and favicons
```

79 characters, fits HN's 80 char limit. Follows the canonical `Show HN: [Name] - [plain
description]` format, and the "Storybook for X" anchor tells a developer the entire
mental model in four words: templates in your repo, a live preview server, rendered
output. No superlatives for dang to neutralize.

## Alternates

Pain angle (highest click-through, but breaks the Name - description convention):

```
Show HN: I got tired of re-exporting app icons into five places
```

Source-of-truth angle (the sharpest value prop, slightly more abstract):

```
Show HN: One source of truth for app icons, screenshots, and favicons
```

Mechanism angle (most literal, good fallback if a relaunch is ever needed):

```
Show HN: App assets as HTML templates, rendered to every size and destination
```

## Rules

- Never edit the title after ranking starts unless a moderator asks.
- If the post dies and you relaunch after the 24h cooldown, switch to the mechanism
  angle title and add the missing context to the first comment. Do not resubmit the
  same title.
- Submit the GitHub URL, not a landing page. HN wants code to read.
