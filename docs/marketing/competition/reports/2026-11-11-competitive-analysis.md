# Open Assets: competitive analysis 2026-11-11

Artifact: https://claude.ai/artifact/5pWefc5UnhWHgsXoAHeNMn

## Verdict

Open Assets is a well-built, genuinely differentiated tool (marketing assets as code, git-versioned, CI-ready, and the only agent-native screenshot tool via its Claude Code skill) but it is nearly undiscoverable: 46 GitHub stars, 543 npm downloads a month, a one-page marketing site, and no presence in search, directories or AI skill registries. The single biggest opportunity is distribution and SEO, not features: deploy the stalled SEO fixes, build out the marketing site, saturate the directories and Claude skill registries, and run the launch the marketing plan already drafts.

Us: None ratings, None avg, Free, MIT, local (no SaaS)

## Competitor complaints (1 to 2 stars)

- **Undiscoverable** %: A web search for 'open-assets' app store screenshots returns nothing relevant; the marketing site sitemap has a single URL (the homepage); memory notes it is not indexed in Bing and SEO fixes sit in an undeployed PR.
- **Install and Chromium friction** %: Open Assets needs Node plus Puppeteer/Chromium, while Previewed, AppLaunchpad, Screenshots Pro and Shots.so are zero-install browser tools; Chromium setup is the main adoption objection for a CLI tool.
- **No video / App Preview** %: Previewed, AppLaunchpad and Shots.so all export video and App Preview clips; Open Assets renders static PNG only, missing a proven App Store conversion surface.
